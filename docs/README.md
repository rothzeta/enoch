# Enoch documentation vault

`docs/` is the Obsidian vault root. Open this directory as a vault; this note is its entry point. The notes also remain readable as ordinary Markdown in Git.

## Start here

- [SCHEMA](SCHEMA.md): vault structure, document roles, and linking rules.
- [CURRENT](CURRENT.md): current implementation state.
- [PROBLEMS](PROBLEMS.md): unresolved issues; only the orchestrator agent may clear entries.
- [TASK_LOGS](TASK_LOGS.md): dated work records and executed verification.
- [Lexicon](lexicon/README.md): the meanings of Enoch terms.
- [ADRs](adr/README.md): accepted decisions and their authority.
- [Plans](plans/README.md): delivery order and bounded task specifications.
- [Exploitation](exploitation/README.md): deployment, operation, and recovery procedures.

Read the relevant ADRs and current evidence before creating a plan or task. A decision describes an obligation, a plan describes intended work, and a task log records what actually happened.

# Agent resources

This mandatory directory holds repository-specific agent workflows and
supporting assets. Start with [AGENTS.md](../AGENTS.md), then read the
[development rules](../docs/exploitation/development.md) and relevant
[ADRs](../docs/adr/README.md).

Keep canonical decisions and code rules in the documentation vault; link them
from resources here. Do not store credentials, private transcripts, or generated
agent state in the repository.
